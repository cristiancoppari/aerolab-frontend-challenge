This is my solution for the [Aerolab](https://github.com/Aerolab/frontend-developer-coding-challenge) challenge.

## Technologies

- [Next.js](https://nextjs.org)
- [Tailwind CSS](https://tailwindcss.com)
- [TypeScript](https://www.typescriptlang.org)
- [React](https://reactjs.org)

## Specifications

- Git flow
- ESLint
- Prettier

## Development

Install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

- Development URL: [http://localhost:3000](http://localhost:3000).
- Production URL: [https://aerolab-frontend-challenge-one.vercel.app](https://aerolab-frontend-challenge-one.vercel.app).
